# Georgia Tech Economic Impact

Interactive map of Georgia Tech's economic impact across Georgia's 12 economic development regions (FY25).

Built by the Georgia Tech Enterprise Innovation Institute — Center for Economic Development Research.

- `index.html` — the self-contained site (map, KPIs, region detail panel). Open it directly in a browser, or it's served live via GitHub Pages at https://cedr.tech.
- `logo.png` — CEDR logo asset.
- `CNAME` — custom domain configuration for GitHub Pages.

The first data layer shows the impact of Georgia Tech employees and their local spending. Additional FY25 layers (research, student spending, construction) can be added as selectable views.
